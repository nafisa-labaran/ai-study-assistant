# AI Study Assistant — Week 1 Deliverables

An AI-powered study assistant designed to help university students understand concepts and revise academic materials.

## Implemented Application

The initial application includes a streaming AI chat interface powered by Google Gemini through the Vercel AI SDK.

Current capabilities include:
- Asking academic questions and receiving AI-generated explanations.
- Viewing responses progressively as they are generated.
- Stopping an ongoing response.
- Retrying failed responses and regenerating answers.
- Displaying loading, error, and screen-reader-friendly status messages.
